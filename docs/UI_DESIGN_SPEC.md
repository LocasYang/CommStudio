# CommStudio Modbus UI 设计规范

版本：2026-10-25 · 设计基线于 2026-10-24 确认；按石墨色效果图实现工作台，移除常驻趋势预览。

## 1. 适用范围与优先级

本规范约束 CommStudio 的共享导航、顶栏和主题，以及 Modbus 通道树、数据工具栏、点表、报文监视及相关弹窗。**结构和操作语义对齐 MThings，视觉使用用户确认的石墨色工作台及对应浅色主题**；不能以“现代化”为由改掉用户指定的树、菜单或嵌套弹窗。

优先级：用户最新明确要求 → 本规范 → MThings 手册与参考截图 → 早期设计建议。当前代码用于记录实现尺寸基线，运行验收另行记录，不代表所有已有实现都是正确规范。需求与实现状态分开记录：功能缺口见 [MODBUS_ROADMAP.md](../MODBUS_ROADMAP.md)。

## 2. 页面与工程模型

应用级导航可在 72 px 图标栏与 210 px 展开栏之间切换，状态保存在独立的 `ui/navigationCollapsed` 设置中。导航切换只改变布局，不修改选中设备、点定义、通道连接或轮询状态。

Modbus 数据工作区采用左侧通道树、右上点表、右下报文监视三个独立面板。面板圆角 7 px，横纵间距均为 14 px；标题、工具栏、内容属于各自面板，不能用一个跨栏大外框包住全部区域。**面板间距处只能显示工作区背景，禁止边框横穿留白，禁止双层描边。** 左树底部显示当前通道真实参数；高度不足时保留端口与连接状态摘要。

按用户最新要求，常驻趋势预览区域移除，报文监视占据右下区域全宽。原有工具栏曲线入口仍打开独立趋势工作台。报文区可收起/重新显示，支持跟随、暂停显示、清屏、导出、展开和通信统计；数据来自当前通道 TrafficModel，不能使用效果图的演示波形、收发数或连接状态冒充运行数据。

报文区的“暂停”只暂停显示，不停止通道通信、读轮询或循环批量写；手动向上浏览时退出自动跟随。清屏须确认，只清理当前报文记录，不删除设备、点定义或任务。导出使用点击导出时所对应的通道报文模型，切换当前设备不能把导出对象静默换成另一个通道。

```text
Channel（串口以 COM11 等端口名为主标题）
└─ Device（同一通道下可有多个设备，Unit ID 属于设备）
   ├─ Point
   ├─ Poll
   ├─ Transaction
   ├─ Trend
   └─ Statistics
```

后五项描述工程归属，**不要求在左树里机械追加五个分类节点**。左树的常态外观就是通道父行和缩进的设备子行，不再叠加“通道 / 名称”表头；打开设备详细信息后才显示对应列表头。选设备后右侧显示其点表。

- 串口通道来自本机 COM 枚举；刷新是重新扫描端口，不能生成 `Channel 2` 等虚构端口。别名单列显示，不取代 COM 标识。
- 网络通道在独立网络分类中管理，不将网络端点混作串口。
- 树内不得插入“设备”大标题、添加卡片或每行配置按钮。节点操作放到右键菜单；上方保留参考图中的集中工具按钮。
- 通道管理弹窗是例外：使用“通道 / 别名 / 状态 / 参数 / 控制”表格，允许行内配置和启动/关闭按钮。
- 串口配置常用字段限定为通道名称、传输协议、波特率、校验、数据位、停止位、流控；Unit ID、组包及设备高级参数不能混入。

### 树的选择必须分清四种状态

| 状态 | 正确行为 |
| --- | --- |
| 展开/折叠 | 只控制子设备是否可见；箭头始终在父行的固定槽位水平、垂直居中。 |
| 当前行高亮 | 点击节点切换上下文；不等于批量勾选，也不等于连接。 |
| 操作勾选 | 初始不勾选；通道框选中其全部子设备，再点取消全部；部分勾选显示半选。设备框可独立取消。 |
| 连接/启用状态 | 独立于高亮和勾选；切换行、展开树不得自动连接设备或启动轮询。 |

树工具栏顺序：通道管理 → 添加设备 → 删除勾选设备 → 启动勾选设备轮询 → 停止轮询 → W（启动/停止循环批量写）→ 分隔线 → 展示/收起设备详细信息。W 来自手册第 66 页批量写入口，不能替换最后的设备详情箭头。

W 空闲时操作明确勾选的设备，各通道先全部预检再启动，不自动连接关闭的通道；运行时再次点击停止各通道的循环写。提示文字必须随运行态切换；读轮询和循环写分别停止。停止不能撤回已经发出的请求。

“详细信息”扩展设备类型、设备 ID、地址列，不是打开配置弹窗。删除设备时内部级联清理所属点和任务，不要求用户手动先删子项；删除需明确确认对象和范围。

点表按当前排列固定如下。使用可辨认的线性图标；禁止用语义不明的字符代替关键图形。每个图标有准确的中文/英文提示与禁用状态。

## 5. 点表列与编辑

简略列固定顺序：序号、名称、数值、指令、写、单位、范围、区块、地址、数量、位偏移、位数。

详细模式在后面增加：系数、偏移、小数位数、传输类型、呈现类型、字节序、字序、轮询、批量写、间隔时间(ms)、超时时间(ms)、重发次数。完整手册中的曲线和存储等参与字段仍按路线图补齐，不把“当前详细列”称为全部功能完成。

“批量写”是独立持久化选项，新增/旧点默认不参与，仅线圈和保持寄存器可勾选；它不与轮询、行多选或行可见性联动。双击“写”列头，对当前设备的参与点执行一次批量写，单击不发送。发送前检查所有指令值、地址偏移及队列容量；发现无效项整批不入队。通过检查不等于设备事务原子性，通信过程中仍可能部分成功。

RTU/TCP 主站循环写使用启动时的设备、指令值、组包、超时、重试及周期快照。运行中改变点值或高级参数，停止并重新启动后生效；切换当前设备不改变已启动目标。按行、按地址、按列表顺序组包；写请求禁止跨地址空洞，不用读请求允许间隔补齐写数据。断线、设备停用/删除时停止对应计划，不留待下次连接补发的旧请求。

- 单击选择或定位活动单元格，Ctrl/Shift 多选；默认不批量选中点。
- 双击“指令”编辑目标值；双击“写”发送单次写入，单击不得发送。只读数据区、未连接或禁用设备不能写。
- 点表写入按点定义编码；手动寄存器测试与工程值输入不能混淆。编码不支持时明确报错，不能静默按整数发送。
- 区块筛选是临时视图；行列可见性与操作选择分离。切换简略/详细不得修改点定义、指令或参与轮询状态。
- 双击地址表头只排序当前设备：区块、地址、位偏移、位数依次升序；其他设备的点定义及顺序不变。
- 输入框、下拉框保持单元格内对齐；箭头固定靠右并垂直居中，不随文本长度偏移。

## 6. 弹窗统一规范（重点：右上角 X）

### 外壳与嵌套

- `parent: Overlay.overlay`，在可用区域居中；`padding: 0`，内容自管留白，宽高均限制在窗口内。
- 模态弹窗 `Popup.CloseOnEscape`；点击遮罩不丢表单。X、取消、Esc 都不提交未保存草稿。
- 子配置弹窗出现时父弹窗保留，状态和滚动位置不丢失；只让最上层接收输入。关闭子层回到父层，不能先销毁父层再打开新窗口冒充嵌套。
- 遮罩不要逐层无控制叠黑；圆角补角与色带必须使用同一不透明颜色，避免顶部/底部出现叠加深条。
- 普通表单采用“标题带 → 内容 → 操作带”；内容过多滚动正文，标题、关闭钮和底部操作始终可达。

### 关闭按钮

- 本模块标准点击区域 34×34，X 图形约 20 px，在区域内双向居中，`focusPolicy: Qt.NoFocus`。
- **紧靠右边，距外壳右缘 12–16 px**，相对于标题带垂直居中。数量胶囊、图标、长标题均不能把 X 推到中间。
- 首选独立锚定右侧；标题右边锚定到关闭按钮左边，至少留 12 px。使用 RowLayout 时必须固定关闭钮宽高，且只让标题区域填充宽度。
- 不能在同一个 Layout 管理的关闭钮上混用 anchors 和 Layout 定位。禁止用多个 `fillWidth` 项均分标题行。
- 常态弱描边、悬停淡主题色、按下反馈清晰；不使用危险删除按钮的大红实心样式。标题栏 X 和工具栏删除 × 的语义不同。

## 7. 筛选与参数弹窗

筛选行/列必须是同一类表格弹窗：上方名称搜索 + 搜索图标，下方“序号 / 名称 / 选择”三列。选择列显示复选框和“已选择/未选择”，搜索隐藏的条目保留草稿选择。确认统一应用；取消、Esc、X 均丢弃草稿。

这里默认“已选择”表示当前可见，不是树的批量操作勾选；不能为满足“树默认不选”而把所有数据行/列隐藏。

设备高级参数使用“参数 / 数值”两列表格，按用户截图保持字段分组和顺序。同步到其他设备再开选择子层，不能关闭高级参数父层。批量修改弹窗标题明确当前字段，例如“批量设置参数目标值（数量）”，不再只提供固定的数量编辑。

高级参数末尾补充“启动后批量写”：关闭 / 单次 / 循环，默认关闭。显式保存后，在通道连接成功或设备由停用恢复时执行；对已启用设备再次点击启用不重复触发。只在 RTU/TCP 主站开放该控件；ASCII 循环/启动批量写尚未接入，不能让用户误认为已支持。正文滚动时该行可达，标题、X、同步/确认/取消固定可见。参数草稿取消不生效。

- `dialogHeader/dialogFooter` 使用不透明令牌色，严禁在补角上再叠透明主题色。主工作区采用浅层色差，表格分隔线降低对比度；不绘制每个单元格的四边框，避免相邻边界叠成粗线。
- 普通操作用 textPrimary/primary；删除用 error，等待/警告用 warning，在线结果用 success。启动按钮不因“启动”二字就做成刺眼的绿色大块。
- 禁用态仍应可辨认；选中背景上的文字、按钮边框不能因叠加透明度而消失。状态不能只靠颜色，还需文字或图标。
- 报文方向统一使用 `Theme.rx/tx`：RX 青色、TX 琥珀色；离线用灰色，仅实际错误用红色。高亮与勾选不是连接指示，未通信的数值保持 `--`。
- 中文 Microsoft YaHei UI，地址/原始数值按场景使用 Consolas；常规表格约 11–13 px，紧凑弹窗标题按层级采用 14–18 px，例如展开报文监视 14、通信统计 16。减小空白和间距优先于缩小可读文字。
- 共用 AppIcon 将矢量路径按 DPR 渲染；颜色 RGB 与透明度分别处理，禁用图标仍可辨认。控件态使用 100 ms、面级变化使用 200 ms。禁止新增装饰动画挤占调试信息。
